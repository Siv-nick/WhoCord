{# Scheme-safe href helper. Jinja autoescape (which Flask enables for .html templates) prevents raw markup injection, but it does NOT stop `javascript:`-scheme URLs from being valid clickable href targets — the browser treats the scheme check as orthogonal to HTML escaping. Every URL-valued field in this template goes through `safe_href()`, which: • allows http, https, mailto (and relative paths starting with /) • collapses everything else (javascript:, data:, vbscript:, file:, unparseable) to "#" This block is defined inline because Jinja macros can't easily be used for the pure-python-style checks we need. #} {% macro safe_href(value) -%} {%- set v = (value or '') | string | trim -%} {%- set low = v | lower -%} {%- if low.startswith('http://') or low.startswith('https://') or low.startswith('mailto:') or v.startswith('/') -%} {{- v | e -}} {%- else -%} # {%- endif -%} {%- endmacro %} {% macro safe_img_src(value) -%} {%- set v = (value or '') | string | trim -%} {%- set low = v | lower -%} {%- if low.startswith('http://') or low.startswith('https://') -%} {{- v | e -}} {%- endif -%} {%- endmacro %}
